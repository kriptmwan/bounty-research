Front-running a victim's signed (signature, initData) executes the victim's own chosen init exactly (no tx-context dependence in NexusBootstrap — zero msg.sender/block.timestamp hits); the submitter gains nothing.
- N5. Same-hash-different-bootstrap: bootstrap address is INSIDE the hashed initData; different bootstrap => different hash. Verified. No collision.

No cross-boundary effect; signer authorized the exact bytes.
- N7. Bootstrap == address(this)/EntryPoint recursion and bootstrapCall reentrancy into initializeAccount mid-init: nested relay calls need a fresh valid signature + unused hash (same-hash nested call hits the already-used mark set BEFORE the delegatecall); nested classic calls hit the consumed transient flag; nested self-calls (outer caller == address(this)) can recurse only at the account's own gas expense (self-OOG, own tx reverts). No privilege gain beyond H-B1's outer self-call itself.
